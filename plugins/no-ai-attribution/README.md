# no-ai-attribution

A `PreToolUse` hook that denies AI attribution in anything that becomes history or
gets published:

- `Co-Authored-By: … Claude …` / `… Anthropic …` trailers
- "Generated with Claude Code" / "Generated by Claude" lines
- `noreply@anthropic.com`, links to Claude Code

## What is checked

- **Bash** commands that write history or talk to a forge: `git commit/tag/notes/merge/
  rebase/cherry-pick/revert/am`, `gh`, `glab`, `curl`. Both the command text (including
  heredocs) and message files it points at (`-F`, `--file`, `--body-file`, `-d @file`).
- **MCP tools** that create or edit PRs, MRs, issues, comments, reviews, notes or commits.

Reading commands (`git log --grep`, `grep`) are not checked: searching for the trailer
is not publishing it.

On a match the command is denied with the reason, and Claude rewrites the text.
